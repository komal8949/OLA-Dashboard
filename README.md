# OLA-Dashboard
# 🚖 OLA Performance Dashboard

An interactive **Power BI dashboard** designed to analyze and visualize **OLA ride performance**, business metrics, and customer trends.  
This project demonstrates an **end-to-end data analytics workflow** — from data cleaning to business insights.

---

## 📊 Project Overview

The **OLA Performance Dashboard** provides insights into:
- Ride bookings and completion trends
- Revenue and fare analysis
- Customer behavior and demand patterns
- City-wise and time-based performance
- Driver efficiency and ride status analysis

This dashboard helps stakeholders make **data-driven operational and business decisions**.

---

## 🧠 Key Objectives

- Analyze overall ride performance and growth trends
- Identify high-demand locations and peak hours
- Track revenue, cancellations, and completion rates
- Understand customer and driver behavior
- Present insights using interactive visualizations

---

## 🛠️ Tools & Technologies Used

- **Power BI** – Data modeling, DAX measures, dashboard creation  
- **Python** – Data cleaning and preprocessing (Pandas, NumPy)  
- **Excel / CSV** – Raw data storage  
- **Jupyter Notebook** – Data exploration and transformation  

---

## 📁 Dataset Description

The dataset contains information such as:
- Ride ID
- Booking date & time
- Pickup and drop locations
- Ride status (Completed / Cancelled)
- Fare amount
- Distance traveled
- Customer & driver IDs

> *(Note: Dataset is either simulated or anonymized for educational purposes.)*

---

## 🔄 Data Analytics Workflow

1. Data Collection  
2. Data Cleaning & Preprocessing (Python)  
3. Exploratory Data Analysis (EDA)  
4. Data Modeling in Power BI  
5. DAX Measures & Calculations  
6. Dashboard Design & Insights Generation  

---

## 📈 Dashboard Features

- 📌 KPI Cards (Total Rides, Revenue, Completion Rate)
- 📌 Time-based Analysis (Daily / Monthly Trends)
- 📌 City-wise Performance
- 📌 Ride Status Breakdown
- 📌 Interactive Filters & Slicers

---

## 🔍 Key Insights

- Peak ride demand occurs during morning and evening hours
- Certain cities contribute significantly higher revenue
- Ride cancellations are higher during peak traffic times
- Weekends show increased average fare values
